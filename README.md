# Python List Operations Demonstration

A Python program that demonstrates fundamental list operations including appending, inserting, extending, removing, sorting, and searching elements.

## 📋 Program Overview

This program creates a list and performs a series of operations to demonstrate common list manipulation techniques in Python:

1. Create an empty list
2. Append multiple elements
3. Insert an element at a specific position
4. Extend the list with another list
5. Remove the last element
6. Sort the list in ascending order
7. Find the index of a specific value

## 🚀 Features

- **Complete List Workflow**: Demonstrates end-to-end list manipulation
- **Step-by-Step Execution**: Each operation is clearly shown with before/after states
- **Educational Focus**: Perfect for learning Python list fundamentals
- **Error Handling**: Includes proper exception handling for value searches
